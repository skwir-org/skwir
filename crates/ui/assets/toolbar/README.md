# Toolbar icons

These symbolic icons were made for bibli and are under its licence
(Apache-2.0, the repository's `LICENSE`): 24 by 24, strokes of 1.8 in
`currentColor`, round caps and joins, so the toolbar tints them
(`crates/ui/src/toolbar.rs`). They share the outline style of icon sets
such as Lucide but none is taken from one (checked 2026-10-07: their
shapes differ).

A new icon is drawn the same way. One taken from an icon set keeps that
set's licence: name the set, the icon and the licence here, and add the
set's notice to the packages beside the crates' (`tools/package/`).
