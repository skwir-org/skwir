# Toolbar icons

Symbolic icons made for Skwir, under its licence (Apache-2.0, the
repository's `LICENSE`). Each is 24 by 24, strokes of 1.8 in `currentColor`
with round caps and joins, so the toolbar can tint it
(`crates/ui/src/toolbar.rs`). They share the outline style of sets such as
Lucide, but none is taken from one (checked 2026-10-07: their shapes
differ).

Draw a new icon the same way. An icon taken from a set keeps that set's
licence: name the set, the icon and the licence here, and add the set's
notice to the packages beside the crates' (`tools/package/`).
