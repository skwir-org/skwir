# Media playback invariants

Read this before touching `crates/media-worker`, `crates/platform/src/media.rs`, `crates/ui/src/media.rs` or the vendored Blade atlas. It is binding, like `AGENTS.md`.

- GStreamer loads only in `bibli-media-worker`. The media provider owns the
  runtime setting; the shared session interface stays independent of GPUI.
- Playback starts paused and follows the selected preview and provider lifetime.
  UI controls enqueue only; child cleanup and pixel I/O belong to the manager.
  Show the shared thumbnail immediately, then an optional native-resolution
  representative poster. Play/Seek cancels extraction and rejects late posters;
  poster work must never change the playback position or delay starting playback.
  Fullscreen controls use one cancellable inactivity timer, never an animation
  loop. Stationary pointer events generated by layout must not reset its deadline;
  hover, scrubbing, menus and keyboard focus protect visible controls.
  Pointer movement must not take focus from an open playback popup.
- Position updates carry command generations too. Discard queued and late old
  state after enqueueing a control. Seek intent stays visible until GStreamer
  completes its asynchronous preroll; an arbitrary timeout or position tolerance
  is not a seek acknowledgment.
- Keep appsink, transfer storage and UI delivery bounded. A frame slot cannot be
  overwritten before acknowledgment. Reject old command generations, release
  replaced GPUI atlas entries, and never write per-frame image files.
- Atlas eviction must cancel pending uploads before recycling texture indices
  and defer physical destruction until in-flight GPU work finishes. GPUI can
  draw several UI scenes before Wayland presents one; keeping only the latest
  preview does not make immediate texture destruction safe. See vendored patch
  `0003-blade-atlas-retirement.patch` and its GPU regression tests.
- GStreamer owns audio/video timing. Decoder events wake the worker and new
  output wakes the UI; never introduce a UI frame timer for playback.
- Track changes re-preroll from READY, then restore position/rate/play state.
  Do not race dynamic subtitle output replacement with paused flushing seeks.
  Keep playbin flags intact and test actual subtitle pixels, not only metadata.
  The manager bounds glibc arenas in the child to limit frame-buffer retention;
  native benchmarks must use the same policy (as `tools/media/check.py` does).
- Generate media with `tools/media/check.py`; report worker-only versus full UI
  latency and combined PSS separately. Clocked fake audio checks timing but do
  not establish audible synchronization or real audio-device behavior.
- A control the worker cannot carry out is a `Rejected` reply carrying the
  command generation, never an `Error`: the manager surfaces it as a transient
  notice and the session continues. Only decoder errors and a lost runtime end
  a session, after which the UI withdraws the controls and returns focus. Gate
  seek and rate on the reported seekability in the UI as well, and skip the
  position restore after a track change on a non-seekable stream.
- The manager owns the single startup deadline and sleeps in one select over
  commands, replies and `CancelToken::subscribe()`; never poll `is_cancelled`
  on a timer from a blocked thread.
- In the worker, bus messages travel through the loop's channel from the sync
  handler, so wake and payload are one object. Install bus and sink handlers
  before the first state change, and never drop or block on that channel from
  a streaming thread.
- GPUI `drop_image` calls run in update/render code, never in prepaint or
  paint: the Blade atlas patch frees retired textures after waiting for the
  previous submission only (see `vendor/gpui/README.bibli.md`).
- The audio picture is `elements/halo.rs`: the cover in a disc, the spectrum
  as rays of dots round it (bass under the cover, treble above, mirrored), a
  glow that swells with the level, in the cover's own colour running to the
  accent. It has no timer: a published spectrum is a frame, and a paused player
  is still (measured: 1 tick of CPU in 4 s). Rays are dots because a circle
  looks the same at any angle, so they are quads in one batch; gpui's path
  pass costs a frame of its own. The cover's colour is worked out once per
  cover (`halo::tint`, weighted by how colourful a pixel is, so a border does
  not wash it out), never per frame. Everything is sized in `paint`.
